HUANGLE V0.35

日常更新
直接运行同目录 Device_Update.command。
脚本先读 device.config.local.json；不存在时读 device.config.json。
Wi-Fi 名称、密码、天气城市及经纬度、USB 串口均由这个文件指定。
不再读取电脑当前网络、不查询钥匙串、不需要 macOS 网络信息权限。
本地配置使用此前提供的 ZTE_LE 网络，未自动检测当前电脑网络。
城市默认为上海；例如杭州可改 city=杭州, latitude=30.2741, longitude=120.1551；南京可改为南京,32.0603,118.7969。
城市名与经纬度必须一起修改。更改后再次运行 command，无须重新编译；配置写入开发板，重启保留。
公开包中的 device.config.json 不含密码。当前本地项目中另有权限 600 的 device.config.local.json，已填此前提供的密码；该文件被 Git 忽略且不进入分享压缩包。
需要使用分享包时，把自己的 device.config.local.json 一同放在项目根目录，或编辑 device.config.json。
USB 串口仍须可用，并关闭其他串口监视器。

显示变化
顶部 TEMP、HUM、TIME、BAT 统一使用原 Wi-Fi 文字所用的 12 点阵字体。
Wi-Fi 改成白色图标，斜线表示未连接；无线网络页显示已连接的完整 SSID。
右侧原图 x=200 处多余竖线已删除。
显示设备名及 DHCP 主机名改为 HUANGLE；项目及更新文件名保留兼容。
底部三个入口保持原位。若日后迁入主菜单，建议用未来几小时预报/降雨提醒替代，但当前未增加这些数据或调整布局。

电池
使用官方 ADC1_CH3 / GPIO4、12dB 衰减、eFuse 曲线校准，分压倍率 3。
每五秒读取 16 次平均并平滑，按官方示例 3.0V 至 4.12V 映射到 0–100%。
这是电压估算，不是库仑计；充电、负载和电池型号都会影响读数。采样/校准失败或电压超范围时显示 --%，不伪造电量。
USB 供电不能可靠判定是否装有电池，请使用实际电池检查。桌面预览中的 87% 是布局测试样例。

面板对比度回退（V0.34）
用户反馈 V0.33 更新后屏幕发灰，已撤回 51Hz 修改，恢复原厂参考 B2=0x02、D8=0x80,0xE9，即 HPM 25.5Hz。其余驱动参数不变。
发灰是否由扫描率变化引起尚未实机确认，此次回退用于恢复此前显示条件。原来的细密阴影闪烁问题仍未解决，不再声称 51Hz 能改善当前面板。
Wi-Fi 图标改为 17×15 像素三层圆弧与小圆点，断开时增加斜线。
更新后检查黑白对比度是否恢复，再单独观察暂停动画时的阴影稳定性。

验证与限制
ESP-IDF 5.5.5 编译通过。配置合法性/秘密不回显测试、按键与天气解析回归测试通过。
原生 U8g2 渲染检查顶部负温、100% 湿度、23:59 和 100% 电池均不越界。
本地资源检查确认多余竖线移除。
尚未实际烧录，未确认 Wi-Fi 接通、城市预报返回、电池精度或面板闪烁改善。

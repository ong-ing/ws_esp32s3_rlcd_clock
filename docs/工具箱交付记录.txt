操作
首页选择“工具箱”后按 KEY 进入。
BOOT 短按：循环选择菜单或底部按钮。
KEY 短按：执行当前选中项。
KEY 长按：工具页面返回工具箱；工具箱返回首页。
PWR 保持硬件电源功能。
工具箱内 BOOT 长按暂不安排额外动作，避免与短按重复触发。
倒计时只能在暂停状态调整分钟数，调整会重新设定完整时长。
番茄钟每个阶段结束后提示，等待按开始进入下一阶段，不自动开始下一轮。
设备监控自动更新，底部按钮可返回工具箱。

计时边界
秒表/倒计时/番茄钟使用单调计时，不受联网校时或时区调整影响。
离开页面后仍继续，多个工具可同时计时。
提醒为屏幕底部常驻文字，不包含声音、震动或手机通知。
重启、断电后计时和计圈重置，不保存到闪存。
日历需要先成功同步北京时间，偏移浏览不修改系统日期。
设备监控桌面预览使用样例数据；固件中来自实际系统采样。

验证
每个模块均通过 ESP-IDF 5.5.5 交叉编译。
最终应用大小 0x190cf0 字节，4MB 应用分区剩余约 61%。
测试覆盖：按键去抖和长短按、计时毫秒回绕、离页计时、倒计时结束/重新开始、运行时禁止改时长、四轮番茄钟与长休息、闰年/世纪年/跨年日历、监控页长短按返回。
天气解析、原按键导航及本地配置回归测试通过。
六个工具页面通过实际 U8g2 绘图库渲染检查。
尚未实机烧录，实际按键手感、长时间运行与电池/网络监控读数需上板确认。
